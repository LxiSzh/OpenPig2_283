# OpenPig2_283

pig2mod 1.20.1-2.8.3 (Forge) 的反编译还原版,原作者 Kakiku,版权归他,仅供学习。

## 构建

装 JDK 17,然后:

```
gradlew build
```

产物在 `build/libs` 里。第一次构建要下 Minecraft,比较慢。

## 几句说明

- 重新构建出来的 jar 和原版逐文件对过,内容一致;生成的 mixin refmap 也和原版一模一样。
- 源码是反编译的,变量名、泛型可能和原作者写的不一样,意思没错。
- 代码里有些字符串长这样 `"m_7041_"`,是反射/调用栈检查用的 SRG 名,构建时不会被转换,生产环境就得是这个名字,别改。
- `assets/pig2mod/libs` 下的 dll 和 jar 是模组自己带的,原样放着。
